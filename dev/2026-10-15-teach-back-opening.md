- [ ] Teach-back opening needs improvement

The opening dialog for teach-back activities is currently the same as for case chats, which is a bit confusing. For teach-back activities, we need an intro bar and a modified opening message.

* Show the intro bar directly above the personality’s first message in the conversation. Students should be able to scroll up to reread it.  
* Style the intro bar in a different color from the chat messages so it’s clearly an instruction panel.  
* Include the activity name, the selected or assigned personality, the topic, and the activity length.  
* For a turn-limited activity, count only messages sent by the student. State the limit as a number of student messages. For a time-limited activity, state the time limit.  
* Use a brief, playful description of the personality, while making clear that they really want to understand the topic and are eager for the student to explain it. This reassurance matters even for a personality like a grandma: the student should know she genuinely wants to learn.

Suggested copy for the intro bar (edit as appropriate, for my approval):

“Welcome to the Teach-Back activity, \[activity name\]\! In this activity, you’ll teach \[personality name\] about \[topic\] from the reading on the left. \[Playful, personality-specific description\]—but \[personality name\] really wants to understand this, so don’t hold back\! You can skim the reading before you answer the first message and refer to it throughout the conversation. You have \[number\] student messages / \[number\] minutes. Good luck\!”

**Personality’s first message**

For teach-back activities, below the intro bar the personality should greet the logged-in student by name, describe the scenario entered by the instructor, explain naturally why they need to understand the instructor-selected topic to handle that scenario, and ask the student to help them understand. (Keep case chat activities as they were.)

Suggested structure for teach-back chat starter (edit as desired):

“Hi, \[student name\]\! I’m \[personality name\]. \[Describe the instructor’s scenario in the personality’s voice.\] I need to understand \[topic\] to \[achieve the scenario’s goal\]. Will you help me understand?”

Make the wording adapt to the actual personality, topic, and scenario so the message reads naturally rather than forcing every activity into a fixed sentence. If the student’s name isn’t available, use a generic greeting.
